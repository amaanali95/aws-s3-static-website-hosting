# AWS S3 Static Website Hosting

## Project Overview
Designed and deployed a static portfolio website using Amazon Web Services (AWS) S3. Configured static website hosting, managed website assets, and applied bucket policies to control public access.

## Objectives
- Host a static website using AWS S3.
- Configure index and error documents.
- Upload and manage website files and assets.
- Configure bucket policies for website access.
- Validate deployment using the S3 website endpoint.

## Technologies Used
- **Cloud Platform:** Amazon Web Services (AWS)
- **AWS Service:** Amazon S3
- **Web Technologies:** HTML, CSS
- **Key Concepts:** Static Website Hosting, Bucket Policies, Metadata Management, Cloud Security

## Implementation Steps
1. Created an S3 bucket for the website.
2. Uploaded the website files and assets.
3. Enabled static website hosting.
4. Configured the index and error documents.
5. Applied the required bucket policy for website access.
6. Tested the deployed website using the S3 website endpoint.

## Key Learnings
- Understanding AWS S3 and static website hosting.
- Managing cloud storage and website assets.
- Configuring bucket policies and access permissions.
- Applying basic cloud security principles.
- Deploying and validating a static website.

## Project Outcome
Successfully deployed a static portfolio website using AWS S3 and gained practical experience in cloud storage, website hosting, access management, and cloud deployment.
